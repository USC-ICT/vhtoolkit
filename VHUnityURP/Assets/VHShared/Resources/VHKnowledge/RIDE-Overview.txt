RIDE, the Rapid Integration & Development Environment - Overview
The RIDE website is https://ride.ict.usc.edu. Information current as of July 2026.

RIDE, the Rapid Integration & Development Environment, is a research and development framework for rapid prototyping in modeling and simulation. It combines government, industry, and academic technologies into a real-time sandbox where new simulation ideas can be built, tested, and demonstrated quickly. RIDE is developed by the Simulations, Architectures & Intelligent Agents (SAIA) Lab at USC ICT, in collaboration with most other ICT Labs, sponsored by the U.S. Army DEVCOM Soldier Center STTC, the Army Research Office, the Navy, and others, and is available under Government Purpose Rights (GPR). A public set of RIDE packages for Unity is published at github.com/USC-ICT/ride.

RIDE's scope is deliberately broad. Its capability areas include terrain and geospatial data, so simulations can run on accurate reconstructions of real-world locations; AI-driven agents and behaviors; scenario creation; virtual humans, where it powers the Virtual Human Toolkit; human-machine teaming research, including work with drones and autonomous vehicles; learning sciences integrations; speech and dialogue AI; audio-visual sensing; and the framework and API layer that ties these together. Individual projects pick the subset they need - the Virtual Human Toolkit, for example, uses the cloud service interfaces, local AI services, and the sensing, speech, language, and behavior technologies.

Architecturally, RIDE is middleware: an engine layer provides rendering, interface, and audio through a game engine; a middleware layer adds prototyping functionality such as networking, cloud and local service interfaces, and simulation technologies; and projects are built on the resulting API. Capabilities have multiple interchangeable implementations behind one interface - typically a choice of vendors, and of cloud versus local services - so a project can switch providers without changing its own code. Technology proven in one project can be folded back into the middleware, where every later project benefits.

The main focus today is the Unity game engine, where RIDE is mature and distributed as Unity packages. The intent, however, is to target multiple simulation environments and game engines through the same concepts and interfaces. Support for Unreal Engine and for Battle Road's AtomEngine is work in progress, and support for JVT, the JTAC Virtual Trainer, and AFSIM, the Advanced Framework for Simulation, Integration, and Modeling, is planned. The goal is that simulation capabilities developed as part of the RIDE framework carry across runtimes.

RIDE supports Windows, macOS, Linux, Android, iOS, WebGL, and AR and VR devices on its Unity path, with the feature set varying by platform.
